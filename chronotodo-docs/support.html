常见问题 (FAQ)

1. 如何在 iPhone 和 Mac 之间同步数据？

只要您的 iPhone 和 Mac 登录了同一个 Apple ID，并在系统设置中为“拾光待办”开启了 iCloud 权限，并在应用内开启云同步后，应用会尝试通过 Apple CloudKit 同步。两端需使用同一云端环境的版本；网络、账户或权限异常可能导致延迟，必要时在设置页触发「立即同步」。

2. 为什么新建的任务没有同步到另一台设备？

请按以下步骤排查：
① 确认两台设备网络连接正常；
② 检查系统设置中「Apple 账户 → iCloud → 使用 iCloud 的 App」是否已开启本应用权限；
③ 将应用切入后台后再切回前台，或点击设置页面的「立即同步」按钮触发同步。

3. 任务提醒没有弹出？

请检查系统设置中的「通知」，确保已允许“拾光待办”发送通知，且未被免打扰模式（专注模式）过滤。

4. 数据会丢失吗？如何备份？

本应用采用“本地优先”架构，数据首先保存在本地 SQLite 数据库中。离线时可使用已保存在设备上的数据。iCloud 提供跨设备同步，同步不是独立备份，修改和删除会传播，也可能因网络或账户异常失败。怀疑数据丢失时请保留各设备现场并联系支持，先不要卸载、清库、重置同步或覆盖另一台设备的数据。

问题反馈与诊断控制

以下新增诊断控制、本地记录与技术报告说明仅适用于包含这些功能的版本。旧版 TestFlight 1.0.0 (3) 不提供这些新增入口，可通过本页支持邮箱反馈。

含本次功能的版本可在「设置 → 诊断与反馈」选择类别并提交技术报告。报告只发送受控类别及随机短时关联信息；提示「SDK 已排队」不代表服务器已收到。问题描述请在邮件客户端自行编辑并发送。

可先「预览技术摘要」，检查后主动复制或通过邮件分享。摘要不含任务正文、账号、原始异常、地址、路径或文件附件。诊断开启时本地 UTF-8 结构化缓冲最多 1 MiB，只提供最近 24 小时的可用诊断；应用加载、读写和导出时清理过期内容，未运行期间无法准点清理。「清除本地记录」不会删除任务或 Sentry 已收到的记录。

关闭「允许诊断采集」会先阻断新的诊断出站并尝试清理本地和待发记录；提示保存或清理失败时请重试关闭。已发出的数据无法撤回。关闭成功持久化后下次启动沿用选择，普通邮件反馈仍可使用。

当前诊断包含 Dart 异常、受控同步诊断、结构化日志和主动技术报告。原生崩溃、ANR、卡顿、watchdog、会话和 NDK 尚未开启，后台没有事件也不能证明没有问题。

反馈时请提供

  • 平台与系统版本、应用版本和构建号、分发来源（Debug / TestFlight / 商店）。
  • 发生时间与时区、用合成任务描述的复现步骤、预期与实际结果、是否必现。
  • 可选：预览后的受控摘要或短时关联码。没有诊断信息也可反馈。

GitHub 工单公开，请勿附联系方式、任务正文、账号、凭据、原始日志、未遮挡截图或完整数据库。必要私密材料通过支持邮箱沟通，先检查分享内容。反馈将按影响范围分级跟进；修复代码、发布新包与用户验收会分别记录，无法承诺全天候响应。
